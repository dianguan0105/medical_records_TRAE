# medical_records_TRAE

# 门诊病例一体化 Skill
> 适用于 TRAE SOLO 的医疗文档智能处理技能
> 录音转写 + 图片 OCR 一体化，自动生成标准门诊病例 Markdown

## 📋 简介
本技能支持医患对话录音转写 + 医疗文档 OCR 识别，自动合并信息并生成一份标准化、结构化的门诊病例 Markdown 文件。支持智能命名、隐私保护、文件去重、全文检索，一站式完成门诊资料整理与存档。

## ✨ 功能特性
- 🎙️ 录音转写总结：自动把医患对话转为文字，并生成临床结构化要点
- 📄 多文档 OCR：支持门诊病历、处方、缴费单、检验/影像报告单
- 🔗 一体化合并：录音 + 图片信息自动融合，生成单份完整病例
- 📝 标准输出：统一 Markdown 模板，结构清晰、便于查阅
- 🏷️ 智能命名：{姓名}-{诊断}-{日期}-{类型}.md 自动命名
- 🔐 隐私保护：一键脱敏身份证、电话、住址等敏感信息
- 📂 文件去重：同名文件自动提示，支持覆盖/追加序号
- 🔎 全文搜索：按姓名、诊断、药品、时间、关键词多维检索

## 🚀 安装方法
1. 将本仓库克隆或下载到本地
2. 将 门诊病例一体化 文件夹复制到 TRAE SOLO 技能目录：
   - Windows: %USERPROFILE%\.trae\skills\
   - macOS: ~/.trae\skills\
   - Linux: ~/.trae\skills\
3. 重启 TRAE SOLO 或刷新技能列表

## 🎯 触发条件
满足任一条件自动激活：
- 上传音频：m4a/mp3/wav（医患对话录音）
- 上传图片：病历、处方、报告单、缴费单
- 同时上传音频 + 图片
- 输入关键词：门诊、病历、处方、报告、缴费、就诊、对话、录音、总结、整理

## 🚦 使用流程
1. 上传录音 / 图片 / 录音+图片
2. 自动语音转写 + OCR 信息提取
3. 信息校验与补全（姓名、日期、诊断）
4. 隐私选项确认（保留/脱敏/取消）
5. 自动合并生成一份标准门诊病例 Markdown
6. 智能命名、去重、保存并返回结果

## 📝 输出文件命名规则
{姓名}-{诊断}-{日期}-{类型}.md

示例：
- 张三-上呼吸道感染-2026-05-28-门诊.md
- 李四-未诊断-2026-05-10-报告.md
- 王五-高血压-2026-05-08-处方.md

## 🔐 隐私保护
生成前必选：
1. 确认，直接生成 — 保留全部信息
2. 隐藏敏感信息后生成 — 证件/电话/住址替换为 ***
3. 取消 — 不生成文件

## 🔍 搜索功能
支持自然语言多维度检索：
- 按姓名：搜索张三的就诊记录
- 按诊断：搜索糖尿病相关记录
- 按药品：搜索含阿莫西林的处方
- 按时间：2026年3月–5月的记录
- 组合条件：张三2026年所有门诊记录

## ⚙️ 技术依赖
本技能基于 TRAE SOLO 内置能力：
- 语音识别（vosk-model-small-cn-0.22）
- 图片 OCR 与信息提取
- 文件读写、检索、目录管理

## ⚠️ 注意事项
1. 首次使用建议指定医疗记录存储目录
2. 图片模糊会影响识别准确度，技能会自动提示
3. 多页文档自动合并为一份 Markdown
4. 同名文件会提示覆盖/追加序号/取消
