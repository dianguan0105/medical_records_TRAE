# medical_records_TRAE

> 适用于 TRAE SOLO 的医疗文档智能处理技能

## 📋 简介

本技能可自动处理医疗相关图片（门诊病历、缴费通知单、处方、报告单等），通过 OCR 提取文字内容，生成规范化的 Markdown 文件，支持智能命名与多维度搜索。

## ✨ 功能特性

- 📄 **多文档类型支持**：门诊病历、处方、缴费通知单、检验/影像报告单
- 🔍 **OCR 智能识别**：自动提取文档中的关键信息
- 📝 **标准化输出**：生成结构化的 Markdown 文件
- 🏷️ **智能命名**：按 `{姓名}-{诊断}-{日期}-{类型}.md` 格式自动命名
- 🔐 **隐私保护**：支持隐藏敏感信息（身份证号、电话、住址等）
- 🔎 **全文搜索**：支持按姓名、诊断、关键词、时间范围等多维度搜索

## 🚀 安装方法

### 方法一：手动安装

1. 将本仓库克隆或下载到本地
2. 将 `门诊病例处理` 文件夹复制到 TRAE SOLO 的技能目录：
   - **Windows**: `%USERPROFILE%\.trae\skills\`
   - **macOS**: `~/.trae/skills/`
   - **Linux**: `~/.trae/skills/`
3. 重启 TRAE SOLO 或刷新技能列表

### 方法二：直接使用

在 TRAE SOLO 中，将技能文件夹放置到用户技能目录即可自动识别。

## 📖 使用方法

### 1. 处理医疗文档图片

直接上传医疗文档图片，技能会自动：

1. 识别文档类型（门诊病历/处方/缴费单/报告单）
2. 提取关键信息
3. 询问是否保留敏感信息
4. 生成标准化的 Markdown 文件

**示例对话：**

```
用户：[上传一张门诊病历图片]
SOLO：我识别到这是一份门诊病历，已提取以下信息：
      - 姓名：患者A
      - 诊断：上呼吸道感染
      - 日期：2026-05-13
      这份文档包含个人敏感信息，确认要生成包含这些信息的 Markdown 文件吗？
用户：确认，直接生成
SOLO：已生成文件：患者A-上呼吸道感染-2026-05-13-门诊.md
```

### 2. 批量处理多张图片

一次上传多张医疗文档图片，技能会汇总提取结果后一次性确认处理。

### 3. 搜索已有记录

使用自然语言搜索已保存的医疗记录：

```
用户：帮我找一下患者A今年所有的就诊记录
用户：搜索包含"阿莫西林"的处方
用户：查找2026年3月到5月的缴费记录
```

## 📁 支持的文档类型

| 文档类型 | 识别特征 |
|---------|---------|
| **门诊病历** | 包含"主诉"、"现病史"、"既往史"、"体格检查"等 |
| **处方** | 包含"Rp."、"用法用量"、"药品名称"、"规格"等 |
| **缴费通知单** | 包含"金额"、"收费项目"、"医保"、"自费"、"合计"等 |
| **报告单** | 包含"检验结果"、"参考范围"、"影像所见"、"诊断意见"等 |

## 📝 输出文件命名规则

生成的 Markdown 文件按以下格式命名：

```
{姓名}-{诊断}-{日期}-{文档类型}.md
```

**示例：**
- `患者A-上呼吸道感染-2026-05-13-门诊.md`
- `患者B-未诊断-2026-05-10-报告.md`
- `患者C-高血压-2026-05-08-处方.md`

## 🔐 隐私保护

处理包含敏感信息的文档时，技能会询问用户：

- **确认，直接生成** — 保留所有原始信息
- **隐藏敏感信息后生成** — 将身份证号、电话、住址等替换为 `***`
- **取消** — 不生成文件

## 🔍 搜索功能

支持多维度搜索：

| 搜索维度 | 示例 |
|---------|------|
| 按姓名 | "搜索患者A的记录" |
| 按诊断 | "搜索糖尿病相关的记录" |
| 按关键词 | "搜索包含'阿莫西林'的记录" |
| 按时间范围 | "搜索2026年3月到5月的记录" |
| 组合搜索 | "搜索患者A 2026年所有的处方" |

## ⚙️ 技术说明

本技能依赖 TRAE SOLO 的以下能力：
- **Read 工具**：读取和 OCR 识别图片内容
- **Glob 工具**：查找文件
- **Grep 工具**：搜索文件内容
- **Write 工具**：生成 Markdown 文件

## 📋 注意事项

1. 首次使用时需要指定医疗记录的存储目录
2. 图片模糊可能导致信息提取不完整，技能会明确告知哪些字段可能不准确
3. 多页文档会合并为同一个 Markdown 文件
4. 同名文件存在时会询问用户处理方式
